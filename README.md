# Esmâ-i Nebî

Peygamber Efendimizin 99 ismini ve anlamlarını arayıp filtreleyebileceğiniz, PDF olarak indirebileceğiniz tek sayfalık web sitesi.

## Yerelde çalıştırma

`index.html` dosyasını tarayıcıda açmanız yeterlidir. PDF indirme özelliği için internet bağlantısı gerekir; PDFMake CDN üzerinden yüklenir.

## GitHub Pages

Depo ayarlarında **Pages** bölümünü açın ve **Deploy from a branch** kaynağını, `main` dalı ve `/ (root)` klasörü olarak seçin. Yayınlandıktan sonra site GitHub Pages adresinizde açılır.
